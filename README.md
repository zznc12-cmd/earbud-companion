# 이어폰 도우미

Android 13 이상에서 무선이어폰으로 새 알림을 읽는 개인용 앱입니다. Kotlin / Jetpack Compose, minSdk 33, targetSdk 36.

## 현재 상태

**0.1.2-preview: 일부 실기기 확인.** 실제 알림 삭제에 따른 낭독 취소, 출력 경로 확인, 오디오 덕킹, 앱별 알림 선택, 오프라인 한국어 TTS, 백그라운드 상태 알림, 빠른 설정 타일을 구현했습니다. S26 + QCY에서 테스트 음성 청취와 알림 치우기 중단을 확인했습니다.

**상단 배너만 위로 숨겼을 때 중단하는 기능은 미완료입니다.** 일반 알림 접근 API는 배너 숨김 이벤트를 제공하지 않습니다. 접근성 서비스는 시스템 UI 이벤트 종류·횟수만 진단하며, 수동 숨김과 자동 사라짐을 추측해 취소하지 않습니다. 자동 사라짐은 낭독을 중단하지 않습니다. S26 실기기에서 신뢰성 있는 구분을 검증하기 전에는 해당 기능을 활성화하지 않습니다.

카톡·문자, 유튜브 덕킹·음량 복귀, 취소 지연 정량 측정, 스피커 전환, 배터리·재부팅 검증은 아직 수행하지 않았습니다. 상세 결과는 `docs/VALIDATION.md`에 기록합니다.

S26에서는 삼성 TTS가 비공개 엔진으로 제한되어 이 앱의 접근이 거부되고 구글로 대체됩니다. 사용 가능한 공개 엔진을 명시적으로 연결하고 소리 탭에서 시스템 기본값과 다른 이유를 안내합니다. 삼성으로 설정했다는 이유만으로 실제 삼성 낭독이라고 표시하지 않습니다.

## 휴대폰 설치

1. GitHub Releases에서 APK를 휴대폰으로 다운로드합니다.
2. APK를 열고 필요하면 해당 브라우저의 `출처를 알 수 없는 앱 설치`를 허용합니다.
3. 앱의 홈 안내에서 블루투스·앱 알림 권한과 알림 접근을 켭니다. 사이드로드 앱의 알림 접근이 차단되면 휴대폰의 앱 정보 메뉴에서 `제한된 설정 허용`을 확인합니다.
4. 휴대폰 TTS 설정에서 **오프라인 한국어 음성**을 설치합니다. 앱을 다시 열어 상태를 확인합니다.
5. 배터리 사용 설정을 `제한 없음`으로 설정합니다. 알림 탭에서 카카오톡·문자 등 원하는 앱을 선택합니다.
6. 이어폰을 연결하고 실제 미디어 출력도 이어폰으로 선택합니다. 기기 종류가 불명확하면 실제 이어폰에 한해 한 번 승인합니다.
7. 알림 읽기를 켜고 테스트 메시지를 받습니다. 빠른 설정 편집에서 `알림 읽기` 타일을 추가할 수 있습니다.

접근성 설정은 필수가 아닙니다. 현재 배너 진단만 제공하므로 일반 사용에는 켜지 않아도 됩니다. ‘알림 자체 삭제’ 중단은 접근성 권한 없이 작동합니다.

## 동작

- 사용자가 선택한 앱의 새 알림만 읽습니다. 연결 전 알림·건너뛴 알림은 재생하지 않습니다.
- 기본은 제목/발신자와 본문 최대 200자, 화면 켜짐 여부 무관, 미디어 음량 유지입니다.
- 본문 길이는 알림 탭에서 20~1,000자를 직접 입력하고 ‘적용’ 또는 키보드 완료로 저장하거나 슬라이더로 조절합니다.
- 통화·방해금지·조용한 시간·30분 쉬기에서는 건너뜁니다. 제목만 읽기와 화면 꺼짐 조건도 선택할 수 있습니다.
- 중복 갱신·그룹 요약·지속 알림을 제외하고 대기열을 최대 20개로 제한합니다. 대기 중 30초를 넘긴 알림은 버립니다.
- 낭독 시 일시적인 오디오 포커스를 요청하고 종료·취소·오류 시 반환합니다. 감쇠량은 시스템/재생 앱이 정하며 일부 앱은 일시정지할 수 있습니다.
- 원본 알림이 삭제되면 현재 낭독·대기 항목을 취소합니다. 다른 알림의 삭제는 현재 낭독을 취소하지 않습니다.
- 출력 경로를 확인하기 전에는 무음만 재생합니다. 이어폰 해제·출력 변경·통화 시 음성 버퍼를 중단합니다. OS의 갑작스러운 재라우팅은 실기기 검증이 필요합니다.
- 오프라인 한국어 음성이 없으면 낭독하지 않습니다. 앱에는 인터넷 권한이 없습니다. 알림 본문을 로그·서버·영구 이력에 저장하지 않고 임시 WAV는 정리합니다.
- 휴대폰 TTS 설정 변경은 다음 낭독부터 반영합니다. 소리 탭에 연결한 엔진·목소리를 표시하고 설정에서 돌아올 때 목록을 새로 확인합니다.
- 검증 탭에서 본문을 입력해 실제 테스트 알림 1개/3개를 만들 수 있습니다. 테스트만 읽어줄 앱 선택을 생략하며, 작동 스위치·본문 길이·이어폰 출력·화면 조건·통화·방해금지·조용한 시간·쉬기는 그대로 적용합니다. 테스트 알림만 삭제하는 버튼은 상태 알림이나 다른 앱 알림을 지우지 않습니다.
- 화면 종료/최근 앱 제거 후에도 상태 알림과 함께 동작합니다. 재부팅은 감시 서비스부터 복구하며, 강제 종료 후에는 앱을 다시 열어야 합니다.

## 빌드와 서명

JDK 17, Android SDK 36, Gradle wrapper 8.13을 사용합니다.

```powershell
.\gradlew.bat :app:testDebugUnitTest :app:lintDebug :app:assembleDebug
powershell -NoProfile -ExecutionPolicy Bypass -File .\scripts\Build-Release.ps1
```

첫 릴리스 빌드에서 개인용 서명키를 사용자 `.android/earbud-companion-signing` 디렉터리에 만들고 프로젝트의 `signing.properties`에 설정합니다. 둘 다 **공개 저장소나 배포 파일에 포함하지 않습니다.** 키와 설정 파일을 별도 안전한 장소에 함께 백업해야 이후 업데이트를 같은 앱으로 설치할 수 있습니다. 키를 새로 만들지 마세요.

APK와 SHA-256은 `dist/`에 생성됩니다. APK는 `apksigner verify --verbose`로 서명을 확인합니다.

## 검증

`docs/VALIDATION.md`의 실제 결과와 남은 항목을 확인하세요. 연결된 기기에서 화면 테스트를 실행하려면:

```powershell
.\gradlew.bat :app:connectedDebugAndroidTest
```

전역 EQ·ANC·주변 소리·터치 제어·서버 요약·자동 답장·스토어 출시는 포함하지 않습니다. 시스템 음질 설정 바로가기와 좌우 테스트는 제공합니다.
