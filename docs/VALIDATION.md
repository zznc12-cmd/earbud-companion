# 검증 상태

검증 날짜: 2026-10-02. 앱 버전: 0.1.1-preview.

## 개발 환경

- Windows, JDK 17, Android SDK 36, Gradle 8.13.
- 초기 빌드 시 연결된 기기 없음. 이후 Tailscale을 통한 무선 ADB로 Galaxy S26 (`SM-S942N`, Android 16 / API 36) 연결 확인.
- 실행 가능한 Android 에뮬레이터가 설치되어 있지 않음.

## 자동 검증

- `:app:testDebugUnitTest`: **20개 통과, 실패 0개**.
  - 알림 정책/대기열 11개: 중복, 오래된 알림, 조용한 시간, 취소된 음성의 늦은 완료, 다른 알림 삭제, 모두 지우기, 알림 폭주 제한.
  - WAV 검증 4개: PCM 디코딩, 손상된 길이, 지원하지 않는 인코딩, 잘린 파일 거부.
  - Robolectric Android API 33 생명주기 5개: 권한 없는 홈 시작, 필수 권한 게이트, 서비스 생성/정리, 시스템 바인딩 권한과 인터넷 권한 없음, 모호한 배너 이벤트에서 취소하지 않음.
- `:app:lintDebug`: **오류 0개**. 남은 경고 11개는 고정한 라이브러리의 새 버전 알림입니다.
- `:app:assembleRelease`: **성공**. 릴리스 APK 크기 약 21 MB.
- `:app:assembleDebugAndroidTest`: **성공**. 화면 테스트 2개는 컴파일/패키징만 확인했으며 실행하지 않았습니다. 휴대폰에는 개인 릴리스 키로 서명한 APK가 설치되어 있어, 디버그 서명 APK로 교체하지 않고 아래 수동 UI 확인을 수행했습니다.
- `apksigner verify --verbose --print-certs`: **v2 서명 검증 성공**. RSA 3072 개인 릴리스 키.
- 앱 식별자 `app.earbud.companion`, 버전 코드 2, minSdk 33 / targetSdk 36.
- 최종 APK SHA-256: `2848d0313b0409d6563765ea34b770ef02d7b05f053db7cc9dc4e623e90ea2c1`.

JVM에서 Android 생명주기를 모사한 결과는 실제 S26 오디오·터치·배터리 검증을 대신하지 않습니다.

## 실기기 설치와 시작 확인

- Galaxy S26에 공개한 서명 APK를 ADB로 설치: `Success`.
- `MainActivity` 시작: `Status: ok`. 화면 캡처에서 한국어 홈 화면과 최초 권한 안내가 표시되는 것을 확인.
- 0.1.1-preview를 `adb install -r`로 업데이트: `Success`. 기존 본문 길이 60자와 권한 상태가 유지됨을 화면에서 확인.
- 알림 탭에서 본문 길이를 숫자로 350자 입력하고 키보드 완료로 저장: 입력칸·현재 값 안내·슬라이더 표시가 모두 350자로 바뀜을 확인.
- 기존 값인 60자로 다시 저장한 뒤 홈 → 알림 탭 이동: 입력칸·현재 값·슬라이더가 60자로 유지됨을 확인.
- 오디오 낭독·덕킹·삭제 동작은 아래 항목대로 추가 검증이 필요합니다. 숫자 입력 UI 확인을 오디오 검증으로 간주하지 않습니다.

## 배너 진단의 제한

진단 서비스는 `com.android.systemui`의 접근성 이벤트 종류/횟수만 메모리에 기록합니다. 노드 내용·본문·터치 좌표를 저장하지 않습니다. 이 이벤트만으로 수동 숨김 원인과 자동 타임아웃을 확인할 수 있는지 검증되지 않았으므로 **낭독 취소 신호로 사용하지 않습니다.** 이 요구사항을 완료로 표시하지 않습니다.
