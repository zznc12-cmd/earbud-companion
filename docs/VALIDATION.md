# 검증 상태

검증 날짜: 2026-10-02. 앱 버전: 0.1.2-preview.

## 개발 환경

- Windows, JDK 17, Android SDK 36, Gradle 8.13.
- 초기 빌드 시 연결된 기기 없음. 이후 Tailscale을 통한 무선 ADB로 Galaxy S26 (`SM-S942N`, Android 16 / API 36) 연결 확인.
- 실행 가능한 Android 에뮬레이터가 설치되어 있지 않음.

## 자동 검증

- `:app:testDebugUnitTest`: **30개 통과, 실패 0개**.
  - 알림 정책/대기열 14개: 중복, 오래된 알림, 조용한 시간, 취소된 음성의 늦은 완료, 다른 알림 삭제, 모두 지우기, 알림 폭주 제한, 테스트 알림 조건, 건너뛴 이유, 실제 삭제 후 같은 내용의 새 알림 재수신.
  - WAV 검증 4개: PCM 디코딩, 손상된 길이, 지원하지 않는 인코딩, 잘린 파일 거부.
  - Robolectric Android API 33 생명주기 5개: 권한 없는 홈 시작, 필수 권한 게이트, 서비스 생성/정리, 시스템 바인딩 권한과 인터넷 권한 없음, 모호한 배너 이벤트에서 취소하지 않음.
  - TTS 세션 4개: 시스템 엔진 변경 시 이전 연결 해제, 초기화 실패 후 재시도, 없는 엔진 차단, 비공개 엔진 대신 공개 엔진을 명시적으로 선택하고 올바르게 표시.
  - 테스트 알림 3개: 실제 알림 3개 생성/식별, 테스트만 삭제하고 다른 상태 알림 유지, 다른 앱의 표식 위조로 앱 선택을 우회하지 못함.
- `:app:lintDebug`: **오류 0개**. 남은 경고 11개는 고정한 라이브러리의 새 버전 알림입니다.
- `:app:assembleRelease`: **성공**. 릴리스 APK 크기 약 21 MB.
- `:app:assembleDebugAndroidTest`: **성공**. 화면 테스트 2개는 컴파일/패키징만 확인했으며 실행하지 않았습니다. 휴대폰에는 개인 릴리스 키로 서명한 APK가 설치되어 있어, 디버그 서명 APK로 교체하지 않고 아래 수동 UI 확인을 수행했습니다.
- `apksigner verify --verbose --print-certs`: **v2 서명 검증 성공**. RSA 3072 개인 릴리스 키.
- 앱 식별자 `app.earbud.companion`, 버전 코드 3, minSdk 33 / targetSdk 36.
- 최종 APK SHA-256: `8dd2d8ee2012f9dff4a5e50a8be3b172a27df34a857721b0587d25cf693f6c28`.

JVM에서 Android 생명주기를 모사한 결과는 실제 S26 오디오·터치·배터리 검증을 대신하지 않습니다.

## 실기기 설치와 시작 확인

- Galaxy S26에 공개한 서명 APK를 ADB로 설치: `Success`.
- `MainActivity` 시작: `Status: ok`. 화면 캡처에서 한국어 홈 화면과 최초 권한 안내가 표시되는 것을 확인.
- 0.1.1-preview를 `adb install -r`로 업데이트: `Success`. 기존 본문 길이 60자와 권한 상태가 유지됨을 화면에서 확인.
- 알림 탭에서 본문 길이를 숫자로 350자 입력하고 키보드 완료로 저장: 입력칸·현재 값 안내·슬라이더 표시가 모두 350자로 바뀜을 확인.
- 기존 값인 60자로 다시 저장한 뒤 홈 → 알림 탭 이동: 입력칸·현재 값·슬라이더가 60자로 유지됨을 확인.
- 0.1.2-preview에서 삼성 기본 TTS 설정과 실제 앱 엔진이 달라지는 문제를 S26 로그로 재현. 기기가 비공개 삼성 엔진 접근을 거부하고 구글로 대체하는 것을 확인.
- 수정 후 화면에 `Google 음성 인식 및 합성`과 기본 삼성 엔진을 사용할 수 없는 이유가 표시되며, 로그에서 구글에 명시적으로 연결하는 것을 확인.
- 앱이 생성한 실제 테스트 알림을 리스너가 수신해 이어폰 경로를 확인한 뒤 AudioTrack으로 재생하고 완료하는 것을 확인.
- 낭독 중 테스트 알림 삭제: 상태가 `알림을 지워 낭독을 중단했습니다`로 변경. 삭제 전 `GAIN_TRANSIENT_MAY_DUCK` 포커스가 있고 삭제 후 활성 포커스가 0개인 것을 확인.
- 사용자 확인: ‘잘 들리고 알림 넘겼을 때 잘 끊겨’, ‘이번에는 들렸어’. 테스트 음성 청취와 알림 치우기 중단 확인으로 기록합니다. 배너만 숨김 지원이나 취소 지연을 정량 측정한 결과로 확대하지 않습니다.
- 최종 APK 업데이트 설치 성공 후 `versionCode=3`, `versionName=0.1.2-preview` 확인. 홈에서 `QCY T13ANC2 APP`, `이어폰으로 들을 준비 완료`, `새 알림을 기다리는 중입니다`와 기존 권한 유지 확인.

## 배너 진단의 제한

진단 서비스는 `com.android.systemui`의 접근성 이벤트 종류/횟수만 메모리에 기록합니다. 노드 내용·본문·터치 좌표를 저장하지 않습니다. 이 이벤트만으로 수동 숨김 원인과 자동 타임아웃을 확인할 수 있는지 검증되지 않았으므로 **낭독 취소 신호로 사용하지 않습니다.** 이 요구사항을 완료로 표시하지 않습니다.

## 삼성 TTS 제한

S26의 기본값은 `com.samsung.SMT`이지만 앱 프로세스의 TextToSpeech 초기화 로그에 비공개 엔진 접근 거부와 `com.google.android.tts` 연결이 나타납니다. 엔진 생성 요청 성공을 실제 삼성 사용으로 간주하지 않습니다. 공개 엔진 목록에서 사용 가능한 엔진을 다시 명시적으로 연결하고, 시스템 기본값과 다른 이유를 표시합니다. 이 기기에서 삼성 엔진 낭독 지원은 완료되지 않았습니다.
