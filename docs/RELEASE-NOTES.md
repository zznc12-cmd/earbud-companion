## 이어폰 도우미 0.1.2-preview

휴대폰에서 아래 APK 파일을 받아 설치할 수 있습니다. Android 13 이상 지원.

### 이번 업데이트

- 휴대폰 TTS 엔진 변경을 다음 낭독에 반영하고 엔진·목소리 이름을 표시합니다. S26에서 삼성 비공개 엔진 접근이 차단되어 구글을 사용하는 사실도 올바르게 안내합니다.
- 검증 탭에서 원하는 본문으로 실제 테스트 알림 1개 또는 연속 3개를 만들고, 테스트 알림만 지울 수 있습니다. 실제 낭독 조건과 삭제 중단 경로를 사용합니다.
- 낭독 완료·실패·테스트 건너뛴 이유를 표시합니다. 앱을 다시 열면 켜둔 감시 기능을 복구합니다.
- 실제 삭제 이후 동일한 내용의 새 알림이 중복으로 제외되는 문제를 수정했습니다.
- 본문 길이 숫자 입력과 기존 설정은 유지합니다. 같은 키로 서명한 업데이트입니다.

### 구현한 기능

- 무선이어폰 출력 확인 후 선택한 앱의 새 알림을 오프라인 한국어 음성으로 읽기.
- 낭독 중 음악·영상의 음량을 낮추도록 요청하고 종료·취소 시 복구.
- 원본 알림이 실제 삭제되면 낭독/음성 생성/대기 항목 취소.
- 목소리·속도·음량·본문 길이, 화면 꺼짐 조건, 조용한 시간.
- 통화·방해금지 중 건너뛰기, 중복 알림 제거, 빠른 설정 타일과 30분 쉬기.
- 선택적인 연결 음량, 좌우 소리 테스트, 시스템 음질 설정 바로가기.

### 아직 완료되지 않은 항목

**상단 배너만 위로 숨겼을 때 낭독 중단은 미완료입니다.** 수동 숨김과 자동 사라짐을 구분하는 S26 실기기 검증이 필요합니다. 접근성 도우미는 화면 변화 진단만 하며, 이 기능을 활성화하지 않습니다.

S26 + QCY T13 ANC 2에서 테스트 음성 청취와 알림 치우기 중단을 확인했습니다. **카톡·문자, 유튜브 덕킹·음량 복귀, 스피커 출력 전환, 0.5초 취소 지연, 장시간 대기·재부팅은 아직 별도 검증이 필요합니다.** 이 릴리스는 미리보기입니다.

S26에서는 삼성 TTS를 시스템 기본값으로 선택해도 이 앱의 삼성 엔진 접근이 차단됩니다. 현재 사용 가능한 공개 구글 엔진으로 낭독하며 소리 탭에 이 이유를 안내합니다. 삼성 TTS 지원으로 표시하지 않습니다.

### 설치 후 설정

홈 화면에서 블루투스·앱 알림 권한, 알림 접근, 오프라인 한국어 음성, 배터리 제한을 확인하세요. 알림 탭에서 읽어줄 앱을 선택하고 알림 읽기를 켜세요. 알림 접근이 차단되면 앱 정보 메뉴의 ‘제한된 설정 허용’을 확인하세요.

앱 자체에는 인터넷 권한이 없으며 알림 본문을 서버나 로그에 저장하지 않습니다. 인증번호 등 시스템이 가린 내용은 읽을 수 없습니다.

APK 서명 검증과 자동 테스트 결과는 저장소 `docs/VALIDATION.md`에 기록합니다. `SHA256SUMS.txt`는 APK 무결성 확인용입니다.
